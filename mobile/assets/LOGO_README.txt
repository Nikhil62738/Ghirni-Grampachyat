PLACE YOUR APP LOGO HERE
========================

Save the Gram Panchayat Ghirni logo image in THIS folder as:

    logo.png

Full path: mobile/assets/logo.png

Requirements (Expo):
  - PNG format, SQUARE, at least 1024x1024 px recommended.
  - Used as the app icon, the Android adaptive icon, and the splash screen
    (configured in mobile/app.json).

IMPORTANT: This file MUST exist before you run `eas build` or `expo start`.
Expo will fail the build if ./assets/logo.png is missing, because app.json
references it as the app icon and splash image.

The logo you shared (the round green Gram Panchayat Ghirni emblem) is ideal.
If you want a tighter app-icon crop, export a 1024x1024 version.

PLACE YOUR LOGO HERE
====================

Save the Gram Panchayat Ghirni logo image in THIS folder as:

    logo.png

Full path: frontend/public/logo.png

Recommended: a square PNG, at least 512x512 px, with a white or transparent
background (the logo you shared works well).

Where it is used automatically once added:
  - Website header emblem (top-left)        -> src/components/GovHeader.jsx
  - Browser tab icon / favicon              -> index.html
  - Apple touch icon (home-screen bookmark) -> index.html

If logo.png is missing, the header gracefully falls back to a "GP" badge,
so the site still works. Just add the file and redeploy Netlify to see the logo.
